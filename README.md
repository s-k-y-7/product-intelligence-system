# Product Intelligence & Validation Platform

A unified platform that aggregates product data from various sources (e-commerce, reviews, YouTube) and generates granular, actionable AI-based product intelligence reports using Gemini AI.

## Tech Stack
- **Backend:** Django REST Framework, SQLite
- **Frontend:** React, Vite, Lucide React
- **AI Integration:** Gemini AI
- **Mock Services:** FastAPI (Unified Mock Server for e-commerce, YouTube, and text review data)

## Project Structure
- `/backend`: Django REST Framework application managing product data, AI intelligence generation, and API endpoints.
- `/frontend`: React/Vite frontend for searching products and viewing intelligence reports.
- `/mock_services`: FastAPI mock server simulating external data providers.

## Focus
- Product data aggregation from mock e-commerce, video, and review sources
- Granular, actionable product insights using Gemini AI
- Unified local development environment
- Structured product intelligence reports and platform comparisons

Status: Functional MVP
